# 📝 ToDo App en React

Aplicación web interactiva para la gestión de tareas personales desarrollada como Proyecto Final en React.js.

## 🚀 Tecnologías Utilizadas

- **React 18** (Vite)
- **React Router DOM** (Navegación SPA)
- **UUID** (Generación de IDs únicos)
- **Local Storage** (Persistencia de datos)
- **CSS3** (Diseño adaptable y limpio)

## 📌 Funcionalidades

- **CRUD Completo**: Crear, ver, editar y eliminar tareas.
- **Filtrado**: Vista dedicada para tareas completadas (`/completadas`).
- **Edición**: Formulario dinámico con parámetros de URL (`/editar/:id`).
- **Persistencia**: Las tareas se guardan automáticamente en el navegador.
